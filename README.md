Hola a todos, les explico un poco sobre este pequeño proyecto, a dia de esta publicacion estoy cursando segundo año del bachillerato tecnologico de la informacion, esta es una tarea que me mandaron 
a hacer hace unos dias, estoy empezando como programador practicamente, se que no es algo avanzado y puede llegar a ser altamente ineficiente, pero lo publico por dos motivos.
El primero es tener un pequeño registro de mis tareas y avanzes, el segundo es poder ayudar a entender un poco el uso de las clases en java a aquellos que esten empezando en java como yo.

Para los que esten empezando en java, esta es una calculadora que tiene las operaciones (+,-,/,*) en distintas clases, cada operacion tiene su propia clase, luego, en una clase "principal" preguntamos
nombre y que operacion desea realisar, con un par de modificaciones puedes hacer que los numeros ingresados tambien los decida el que ejecute el pequeño proyecto, luego de pedir la informacion el programa
llama a la clase seleccionada por el usuario, le da la informacion ingresada por el usuario y la clase llamada da el resultado, imrimiendose en la consola como resultado.
